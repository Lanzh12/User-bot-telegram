# 🚀 Konfigurasi Awal

Sebelum menjalankan project ini, kamu **WAJIB mengisi konfigurasi berikut**:

```js
// --- KONFIGURASI ---
const apiId = "";      // wajib diisi
const apiHash = "";    // wajib diisi
🔑 Cara Mendapatkan API ID & API Hash
Untuk mendapatkan apiId dan apiHash, ikuti langkah berikut:
Buka website resmi Telegram: 👉 https://my.telegram.org⁠�
Login menggunakan nomor Telegram kamu.
Pilih menu "API development tools"
Isi data yang diminta, seperti:
App title
Short name
Setelah itu, kamu akan mendapatkan:
apiId
apiHash
Masukkan data tersebut ke dalam konfigurasi:
JavaScript
const apiId = "ISI_API_ID_KAMU";
const apiHash = "ISI_API_HASH_KAMU";
⚠️ Catatan Penting
Pastikan semua konfigurasi sudah terisi dengan benar sebelum menjalankan program.
Jangan membagikan apiHash ke orang lain karena bersifat rahasia.
Gunakan data asli milik kamu sendiri.
